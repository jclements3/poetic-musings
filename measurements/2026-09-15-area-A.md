## Summary

- Fits: everything except pm_blob is small (largest real block is the DDC at 2.4k LUT). Sum excluding pm_blob ≈ 7.9k LUT4 / 53 BRAM / 39 DSP.
- Oversized: **pm_blob** (35k LUT, no Fmax) — must be restructured before any full-system fit. **Goertzel** 16 DSP and **Ddc** 18 DSP vs SWAG 2/12 (the 85F has 156, so fine alone; matters for "everything resident").
- Below 100 MHz: pm_ks4/pm_ks49 (~25 MHz), Goertzel (22), pm_audio (52), AmDemod/Ddc (80), pm_seq (99.3). KS needs its string update pipelined (the 49-string schedule at 96 kHz needs ≥4.7 M updates/s, so 24 MHz is still 5× headroom, but it blocks a 100 MHz system clock); Goertzel/audio are audio-rate and can run in a slow domain or be pipelined.
- Skipped: none. PM.Lfo/Rhythm/Seq had no topEntity; minimal `topEntity` + Synthesize wrappers were added (uncommitted).
- Toolchain notes: pm-dsp's `cabal run clash` cannot be used with the 1.10 clash binary (prelude hash check); the store's `clash-ghc-1.8.5-e-clash-23ea…/bin/clash` works. pm_ks49 Clash compile took 40 min / 1.6 GB; the box hit 100% disk and OOM-killed several clash runs mid-session (shared with other agents), so timings are not repeatable.
