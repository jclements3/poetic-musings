Interface Control Document

Four interfaces hold MAIDEN together: the Ch. 10 file each station writes, the TMATS record that describes it, the conversion of native airborne logs into the same container, and the in-software state-vector interface that everything downstream consumes. Change any of these only by revising this document.

The converter writes a TMATS record naming the airframe, logger serial, mass, and mount position, and a Ch. 1 time channel built from GPS time so the airborne file aligns with station files without a manual offset (SYS-006).

IF-4 · State-vector interface SW-001

Everything above the ingest layer consumes this and nothing else. New sensors or log formats are adapters that emit it.

@dataclass
class StateSample:
    t_utc:   float          # seconds, from IRIG-B / GPS
    source:  str            # "A" | "B" | "C" | "FUSED" | "TRUTH"
    az_deg:  float | None   # station-frame azimuth (stations)
    el_deg:  float | None
    conf:    float | None   # tracker confidence 0–1
    v_r:     float | None   # radial velocity m/s (stations)
    pos_enu: tuple | None   # E,N,U metres in field frame (FUSED, TRUTH)
    vel_enu: tuple | None
    att_rpy: tuple | None   # roll, pitch, yaw deg (TRUTH; FUSED if estimable)
    cov:     np.ndarray | None  # 6x6 for FUSED

@dataclass
class Event:
    t_utc: float; kind: str   # "TAKEOFF" | "TOUCHDOWN" | "MANEUVER_START" | ...
    data: dict

Field frame: ENU with origin at Station A survey point, north from the survey heading. Defined once in TMATS; every downstream module uses it.

Time and synchronization SYS-006

  • Each station: GPS receiver → PPS → FPGA; FPGA generates IRIG-B and timestamps every video frame and PCM minor frame against it.
  • Ch. 10 packet RTC is mapped to IRIG-B by the Ch. 1 time packets; ingest resolves every sample to UTC.
  • Airborne: GPS time from the logger; conversion emits Ch. 1 time packets from it.
  • Fallback: a hand clap / motor spool-up visible in all three videos and the IMU gives a manual offset; flagged in the report as degraded sync.
  • Verified by VT-02.
