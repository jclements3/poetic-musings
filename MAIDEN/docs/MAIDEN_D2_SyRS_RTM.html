System Requirements Specification and Requirements Traceability Matrix

Every "shall" in the project lives here, once. Each requirement is allocated to a segment, assigned a verification method, and traced forward to a design element in D3 Architecture / D6 Design and a test in D7 V&V Plan. Results come back in D8 Validation Report. This is the EIA-632 traceability thread.

Traceability thread

Numbering and verification methods

Prefixes

  • SYS system-level performance and function
  • GS ground station
  • AB airborne truth logger
  • SW software and process

Verification methods

  • Test — measured against truth or instruments
  • Demonstration — shown to work, no quantitative truth
  • Analysis — computed or statistically derived
  • Inspection — examined: file, record, mass, config
