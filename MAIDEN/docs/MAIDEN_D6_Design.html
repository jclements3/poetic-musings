Design Description

How each element in D3 Architecture is actually built. Requirement IDs show what each design element satisfies; interface details are in D4 ICD; how each element is tested is in D7 V&V Plan.

Ground station GS-001 – GS-007

Radar front end

Module. Baseline CDM324 (24.125 GHz, I/Q outputs) for better Doppler resolution per m/s and a smaller horn; HB100 (10.525 GHz) as the fallback if 24 GHz range on foam proves short. TBD after VT-05. Antenna. 3D-printed pyramidal horn, ~15 dBi, copper-tape lined. Gain. Two-stage op-amp LNA, 40 dB, 2nd-order anti-alias at 20 kHz. A 30 m/s target gives f_d ≈ 4.8 kHz at 24 GHz (2.1 kHz at 10.5 GHz). GS-003

FPGA DSP

Lattice/Xilinx low-cost dev board. Pipeline: 16-bit 48 kS/s I/Q → CIC decimate ×R — R = 4 at 24.125 GHz (±37 m/s unambiguous), 8 at 10.525 GHz; a fixed ↓8 at 24 GHz gives only ±18.6 m/s and aliases ~30 m/s pattern targets (see results/design-notes/decimation-audit.md; default R pends VT-05) → 512-point FFT every 20 ms (50 Hz) → CFAR peak detection → velocity = f_d·λ/2 with sign from I/Q phase → UART/SPI to recorder. Raw I/Q also streamed so the algorithm can be rerun offline. Resource note (Prototype, maiden35): the sim-verified RTL with behavioral RAM synthesizes far beyond iCE40 hx8k (no BRAM inferred); a BRAM-explicit memory rewrite is required before place-and-route, with ECP5 (ULX3S) the likely target — final board call at bench bring-up. GS-002

Camera capture

1080p30 global-shutter USB3 machine-vision camera on A and C (60° lens), narrower 35° lens on B for pixel scale at range. Frame strobe from the camera goes to an FPGA GPIO, which latches IRIG-B time per frame; the capture host encodes H.264 and hands frames + stamps to the recorder. GS-001

IRIG-B time source

u-blox GNSS with PPS → FPGA generates IRIG-B (DC level shift) and maintains the 10 MHz RTC used for Ch. 10 packet headers. PPS lock state is logged in Ch 6. SYS-006

Ch. 10 recorder

SBC (Raspberry Pi 5 class) running a Python/C recorder built on irig106lib: writes TMATS first, then interleaves time, video, PCM, and message packets by RTC. One file per session. SYS-005

Power and enclosure

4S LiFePO₄ 10 Ah → 5 V / 12 V rails, ≥ 3 h. Weatherproof case on a surveyor tripod with a leveling head and a sighting rail for heading. GS-006, GS-007

Survey and calibration procedure

  1. Set tripod; level; mark ground point.
  2. Log 5 min of GNSS at the mark (RTK if base available) → position in TMATS.
  3. Sight a surveyed far landmark through the rail; read heading; verify with a second landmark.
  4. Checkerboard at 5–10 m in 12 poses → intrinsics; reprojection ≤ 0.5 px.
  5. Radar boresight: walk a corner reflector across the beam; confirm peak at rail heading.

GS-004, GS-005; tested by VT-06/VT-07.

Airborne 6-DOF truth logger AB-001 – AB-003

Option 1 (baseline): Matek H743 flight controller running ArduPlane in log-only mode with an M10 GNSS (RTK-capable F9P on the larger airframe), internal IMU and baro; logs DataFlash .bin at 10 Hz GPS / 100 Hz IMU. Option 2: standalone GNSS+IMU logger if Option 1 exceeds 60 g on the pattern ship. Mount: 3D-printed cradle on the CG, foam-isolated. Option decision by Sep.

Log → Ch. 10 converter

Python; parsers per D4 ICD; emits TMATS (airframe, logger serial, mount offset), Ch 1 time from GPS week/ms, PCM channels for GPS/IMU/BARO/ATT. Verified by VT-09.

Processing software SW-001 – SW-005

Ingest

PyChapter10 / irig106lib wrapper; TMATS parsed into a Station or Aircraft descriptor; every packet becomes a StateSample per D4 ICD. Adapters for native logs live beside it and emit the same type. SW-001

Video tracker

Two-stage: background/sky model + motion to propose candidates, then a small YOLO-class detector (trained on twin-rendered and labeled field frames) to confirm; a 2D Kalman track per station gives az/el via the intrinsics, with confidence from detector score and track age. Target ≥ 6 px. SW-002

Fusion EKF

State [E N U vE vN vU], constant-velocity with process noise tuned to aerobatic g. Measurements: az/el from each station (nonlinear, station pose from TMATS), v_r from each radar (projection of velocity on the station→target unit vector). Handles missing measurements, lags stations to a common epoch, and publishes the 6×6 covariance that feeds confidence bands in the report. Initialization from the first A+B pair. SYS-001–SYS-004

Maneuver segmentation and recognition

Features on a sliding window: path curvature, heading rate, vertical-plane angle, altitude and speed profiles, roll-rate proxy from lateral acceleration. A small temporal CNN/GRU classifies loop, roll, stall turn, Immelmann, level leg, and "other"; segment boundaries from class changes with hysteresis. Trained on twin sequences, fine-tuned on labeled validation flights. SW-003

Scoring

Rubric layer: deterministic geometry checks per AMA maneuver description (roundness as radius variance, centering as offset from pattern-box center line, track as heading deviation, entry/exit altitude match). Calibration layer: a monotone regression from rubric deductions to judge scores, fit on the validation flights and reported with r. SYS-007, SYS-008

Field-rule checker and approach metrics

Flight line and no-fly polygons from the survey; crossings are Events. Approach: final-leg segment → glideslope fit, threshold speed from C's radar and fusion, touchdown from vertical-speed zero plus C's video. SYS-009, SYS-010

Report

One page: scores table, geometry overlay per maneuver, approach panel, top deductions in plain language, confidence bands from EKF covariance and the validation residuals in D8 Validation Report. Clips cut from Station A video. JSON sidecar for archive. SYS-011

Digital twin

Scripted 6-DOF flight model (ideal Sportsman sequence with adjustable imperfections) → synthetic truth; projected through station poses and intrinsics to az/el with pixel noise, and through station→target geometry to v_r with Doppler noise; optional drop-outs and sun-crossing. Writes real .ch10 files so the whole pipeline, including ingest, runs unchanged. SW-004

CI

GitHub Actions: unit tests on parsers and TMATS; replay the HIL set (recorded bench Station 1) and the twin set; compare fused track to twin truth and fail the build if SYS-002/003/004 regress. SW-005
