Reading order

New to the project: D1 → D3 → D5. Building something: D2 → D4 → D6. Testing it: D7 → D8. Using it at the field: D9.

Reviews fold into the milestones. Basic Plan = SRR + SFR · Prototype = CDR + TRR · Field Demo = SVR (FCA/PCA). Each review is a short self-review against the checklist in D5 SEMP.

Conventions

  • Requirement IDs look like SYS-002 and are defined only in D2 SyRS + RTM. Other documents cite them; they never restate them.
  • Verification test IDs look like VT-10 and are defined only in D7 V&V Plan.
  • Items still to be decided are marked TBD.
  • All documents carry the same revision and date in the footer; they are released together at each milestone.
