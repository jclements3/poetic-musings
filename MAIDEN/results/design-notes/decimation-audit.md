# Decimation audit — D6 §FPGA DSP "CIC ↓8" (maiden33)

**Verdict: D6's fixed ↓8 aliases the design's own baseline module at
pattern speeds. Decimation becomes a generic `R`; default R = 4 for the
24.125 GHz CDM324, R = 8 acceptable only if VT-05 settles on the
10.525 GHz HB100.**

## Derivation

The decimated **complex** sample rate sets the unambiguous Doppler span:
with I/Q sampling at f_s, the FFT covers −f_s/2 … +f_s/2 (sign of the
Doppler shift is preserved by quadrature — there is no real-signal
mirror to halve it).

- ADC rate: 48 kS/s I/Q (D6, D4 IF-1 Ch 3).
- D6 as written: CIC ↓8 → f_s = 6 kS/s → unambiguous ±3 kHz.

Doppler scale factors (f_d = 2v/λ, lesson 16):

| Band | f_d per m/s | 30 m/s radial |
|---|---|---|
| 24.125 GHz (CDM324, baseline) | ≈ 161 Hz | ≈ 4.83 kHz |
| 10.525 GHz (HB100, fallback) | ≈ 70 Hz | ≈ 2.11 kHz |

At 24 GHz, ±3 kHz corresponds to **±18.6 m/s**. A pattern ship crosses
the box at ~30 m/s radial ⇒ 4.83 kHz, which folds:
4.83 kHz − 6 kHz = **−1.17 kHz ⇒ reported ≈ −7.3 m/s** — wrong magnitude
*and* wrong sign. At 10.5 GHz, 2.11 kHz < 3 kHz: fits with gust margin.

## Fix

Make R a generic on `cic_dec` (done in maiden34); per-band defaults:

- **R = 4 at 24.125 GHz**: f_s = 12 kS/s → ±6 kHz → **±37.3 m/s**
  unambiguous. Bin width 12 000/512 = 23.44 Hz ⇒ **0.1456 m/s per bin** —
  still far finer than SYS-003's 1.0 m/s RMS needs (margin ≈ 7×).
- **R = 8 at 10.525 GHz**: ±3 kHz → ±42.9 m/s at 70 Hz per m/s. Bin
  11.72 Hz ⇒ 0.167 m/s.

Default build pends VT-05's module decision (GS-003 range test): CDM324
survives ⇒ R = 4 ships; HB100 wins ⇒ R = 8 ships. Either way the RTL is
identical — one generic.

D2 check: **GS-002's wording survives unchanged** — "radial velocity at
≥ 50 Hz from the CW Doppler chain" is decimation-independent (the 50 Hz
epoch tick and v_r output are unaffected by R). No D2 edit needed; this
commit touches D6 + this note only, per D5 change control.

## Exhibit

Alias fold demonstrated by the golden model (lesson 17 Explore 1):
R = 8 with 24 GHz constants, commanded +30 m/s target, reported velocity

## Statement for the record (maiden33 "Done when")

The decimated complex rate sets the unambiguous span because the complex
FFT's full −f_s/2…+f_s/2 range is the only interval a Doppler tone can
land in; anything outside folds modulo f_s. The default build uses
**R = 4** pending VT-05.
