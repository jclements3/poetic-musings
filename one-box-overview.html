ONE BOX — PANEL+ORACLE ROOT AND ITS SPOKES

One Clash library, one root (Panel body + Oracle brains), one case; every other assembly is a spoke that adds hardware to the root. The Panel — the 3D-printed control surface below, with Oracle as the brains behind its user interface — is the demonstrator for the Clash library; theremin, harp, HWIL, radar, games all plug into it. ULX3S ECP5-85F is the only board in the box; Santa Glide (C) runs standalone on an Alchitry Cu.
