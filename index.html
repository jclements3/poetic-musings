Platform Pillars

IaC · Terraform

AWS applied & verified

Dual-cloud platform module: VPC across 2 AZs, KMS-encrypted immutable-tag ECR, encrypted/versioned S3 with a separate access-log bucket, least-privilege IAM role for CI — plus an Azure module (ACR, geo-redundant storage). AWS side apply'd for real against a free-tier account, verified via the AWS CLI, then destroy'd — caught a real bug (CloudWatch Logs needs an explicit KMS key-policy grant, not covered by the default account-root policy). Azure side remains written-only (no subscription available).

Containers · Docker

Built & tested

Hardened multi-stage Dockerfile: minimal base, non-root uid/gid 10001, no build tools in the runtime layer. Actually built and run under --read-only --user 10001:10001 to prove it — caught a real bug (gunicorn needs a writable /tmp even in a locked-down container).

  • 2-stage build: builder → runtime
  • Endpoints: /, /status.json
  • /healthz (liveness), /readyz (readiness)
  • Pinned: flask==3.0.3, gunicorn==22.0.0

Kubernetes

Validated, no live cluster

Restricted Pod Security Standard: non-root, readOnlyRootFilesystem, all capabilities dropped, seccomp default. Default-deny NetworkPolicy, a PodDisruptionBudget, Kustomize base + dev/prod overlays. Manifests parse and build cleanly; never scheduled on a real cluster.

  • 1 Deployment, 1 Service
  • 3 NetworkPolicy (deny, ingress, DNS)
  • 1 PodDisruptionBudget
  • dev: 1 replica · prod: 3 replicas
