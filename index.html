Containers · Docker

Built & tested

Hardened multi-stage Dockerfile: minimal base, non-root uid/gid 10001, no build tools in the runtime layer. Actually built and run under --read-only --user 10001:10001 to prove it — caught a real bug (gunicorn needs a writable /tmp even in a locked-down container).

  • 2-stage build: builder → runtime
  • Endpoints: /, /status.json
  • /healthz (liveness), /readyz (readiness)
  • Pinned: flask==3.0.3, gunicorn==22.0.0

Kubernetes

Validated, no live cluster

Restricted Pod Security Standard: non-root, readOnlyRootFilesystem, all capabilities dropped, seccomp default. Default-deny NetworkPolicy, a PodDisruptionBudget, Kustomize base + dev/prod overlays. Manifests parse and build cleanly; never scheduled on a real cluster.

  • 1 Deployment, 1 Service
  • 3 NetworkPolicy (deny, ingress, DNS)
  • 1 PodDisruptionBudget
  • dev: 1 replica · prod: 3 replicas

Term Reference

Every linked term above jumps here and hovers with its definition inline.

IaC
Infrastructure as Code: describing infrastructure in version-controlled text instead of manual console clicks.
VPC
Virtual Private Cloud: your own private, isolated network inside a cloud provider's infrastructure.
ECR
Elastic Container Registry: AWS's managed registry for storing and scanning container images.
S3
Simple Storage Service: AWS's object storage for files and blobs at effectively unlimited scale.
IAM
Identity and Access Management: the system for controlling who or what can do what to which resource.
Kubernetes (K8s)
A system for running and automatically managing many containers across many machines.
Pod Security Standards
Kubernetes' three built-in security profiles for Pods: privileged, baseline, and restricted (strictest).
NetworkPolicy
A Kubernetes firewall for Pod-to-Pod traffic, usually written as a default-deny rule plus explicit allows.
PodDisruptionBudget
Guarantees a minimum number of replicas stay available during voluntary disruption like a node drain or cluster upgrade.
Kustomize
A kubectl-native tool for patching a shared base of Kubernetes manifests per environment, without duplicating YAML.
CI/CD
Continuous Integration / Continuous Delivery (or Deployment): automatically building, testing, and releasing code on every change.
Shift left
Moving security checks as early as possible in the development timeline, ideally into the automated pipeline at commit time, instead of a late pre-launch review.
SARIF
Static Analysis Results Interchange Format: a standard format for security scan results so different tools' findings can be viewed in one place.
SAST
Static Application Security Testing: analyzing source code for security-relevant patterns without running it.
SBOM
Software Bill of Materials: a complete, machine-readable inventory of every dependency a piece of software uses.
SCA
Software Composition Analysis: checking a dependency inventory against a database of known vulnerabilities.
CVE
Common Vulnerabilities and Exposures: the standard public naming/numbering system for disclosed security vulnerabilities.
CIS
Center for Internet Security: publisher of the CIS Benchmarks, versioned hardening checklists for specific systems.
Prometheus
An open-source system that periodically scrapes and stores time-series metrics from configured targets.
Grafana
A dashboard/visualization layer that queries Prometheus (and other sources) to render graphs, gauges, and alerts.
AD
Active Directory: Microsoft's directory service for identity, authentication, and authorization across an organization's users, computers, and groups.
GPO
Group Policy Object: a declared configuration/security setting that Active Directory pushes automatically to computers or users in its scope.
MECM/SCCM
Microsoft Endpoint Configuration Manager (formerly SCCM): tooling for managing on-premises Windows devices at scale.
Coder
A platform for provisioning and managing remote, browser-accessible development environments from standard, version-controlled workspace templates.
